# vibe-trading-feed

Read-only data feed for the **Vibe-Trading Paper Portfolio** dashboard (built in Grok Build).

- `latest.json`: the current snapshot of a $1,000 **paper** (simulated) trading account started 2026-10-26, compared with SPY buy-and-hold. Updated a few times each trading day.
- `SCHEMA.md`: field-by-field description.

Paper trading only. Not investment advice. Backtests and paper results don't promise future returns. No broker is connected and nothing here places orders.

Raw URL: https://raw.githubusercontent.com/mattaslan817/vibe-trading-feed/main/latest.json
